Um elemento só, embaixo no centro, e o próximo sempre substitui o anterior — nunca empilhe. A cor é uma inversão literal, não um novo token: fundo `fg`, texto `bg`. Some sozinho em 3 segundos (5 com `Desfazer`); não tem botão de fechar nem ícone. `Desfazer` é a única ação de texto dentro do toast, sublinhada, na mesma cor do resto (`bg`) — não use `acc` aqui, porque o toast já é uma superfície invertida e `acc` não foi desenhado para esse fundo.
