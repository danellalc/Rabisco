A tela de entrar é uma só, em dois passos que se substituem no mesmo lugar — nunca duas telas separadas. O nome `Rabisco` é `h2`, texto puro, nunca uma imagem ou logotipo. Erro de validação (`E-mail inválido`, `Código inválido ou expirado`, `Muitas tentativas. Espere um minuto`) usa `c1` numa linha abaixo do campo — nunca um toast. O campo com erro troca só a cor da borda inferior, de `line` para `c1`; não adicione ícone de alerta.

O botão de ação primária (`Receber código`, `Entrar`) é a única aplicação de borda em `acc` do sistema: 1,5px, `radius-4`, fundo `bg`, texto `acc`. Desabilitado (`Enviando…`), ele perde a cor: borda `line`, texto `fg2` — nunca opacidade reduzida, que já é usada para upload de imagem e teria um significado diferente aqui. `Reenviar código` e `Trocar e-mail` são links de texto (`acc` sublinhado), nunca botões.
