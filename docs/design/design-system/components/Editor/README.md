A primeira linha de qualquer nota é sempre `h1` — é o título, não um parágrafo maior; não existe um estilo de título separado. Os únicos blocos que existem são `h1`, `h2`, parágrafo (`body`), lista com marcador, lista numerada, checklist e imagem (ver componente `ImageBlock`) — não adicione citação, código ou tabela: não fazem parte do escopo do Rabisco. `line-height: 1.5` é o mesmo em todo bloco, título incluído; não aperte o `h1` para parecer mais "de título".

Checklist usa os caracteres `☐`/`☑`, nunca uma caixa desenhada — isso é um controle de teclado/toque simples, não um componente com estado de hover. Item marcado fica esmaecido em `fg2`; riscado (`text-decoration: line-through`) é uma formatação separada que a pessoa aplica por cima, não o padrão do item concluído.
