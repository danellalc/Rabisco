Dezoito controles, nunca mais: negrito, itálico, sublinhado, riscado; H1, H2; três ícones de lista; três marca-textos e remover; três cores de texto e padrão; limpar formatação. `B`/`I`/`H1`/`H2` são letras no peso e estilo que representam — não troque por um ícone mesmo se parecer "mais limpo"; a barra é tipografada de propósito. Os separadores entre grupos são um traço de 1px em `line`, nunca espaço extra sozinho — é o que deixa os 18 controles legíveis como 6 grupos, não como uma fileira solta.

A barra inteira usa só `bg2` + `radius-4` — sem sombra. Sombra é `shadow-1`, e `shadow-1` existe só no popover e no toast; a barra de formatação não é uma dessas duas coisas, então fica achatada na página mesmo flutuando sobre a seleção no desktop. Estado ativo de um controle de formatação (B, por exemplo) é só `bg`; estado "selecionado" de uma bolinha de cor é um anel de `acc` — a única vez que `acc` desenha uma forma fechada, e mesmo assim é um contorno, não um preenchimento. No celular, os 18 controles viram duas linhas de nove — nunca uma linha espremida ou um scroll horizontal escondendo metade dos controles.
