A lista inteira vive em `bg` — o mesmo fundo do editor, nunca um painel com cor própria; é uma folha só, só que com outra composição. `bg2` aparece exatamente numa linha desta lista: o item ativo. Ele ganha `radius-4` e nada mais — sem borda, sem sombra, sem indicador lateral colorido.

Cada linha mostra só duas informações, ambas já definidas nos tokens de tipografia: `body` para o título (uma linha, `text-overflow: ellipsis`) e `meta` para o tempo relativo, alinhado à direita. A microcópia do tempo continua minúscula (`agora`, `ontem`, `12 set`) — o `text-transform: uppercase` é só apresentação via CSS, não mude o texto-fonte. O alfinete usa o ícone `alfinete` em `fg2`, 14px, antes do título; ele é só indicador — fixar/desafixar vivem no menu da nota, não aqui. Nota só-imagem ganha uma miniatura de 40px em `bg2` à direita; nota com texto e imagem não tem miniatura. O rodapé (e-mail + `Sair`) é a única "tela de configurações" do produto — não adicione mais nada nele.
