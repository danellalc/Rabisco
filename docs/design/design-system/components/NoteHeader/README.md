O cabeçalho é sempre os mesmos quatro elementos, só o primeiro ícone muda com a largura da tela: `voltar` abaixo de `breakpoint`, `recolher-lista` acima. Nenhum dos quatro ganha um fundo, círculo ou área de toque desenhada como botão — eles são texto e ícone soltos, do tamanho do próprio glifo (a área de toque de 40px é invisível, por padding, não por uma forma visual).

`Compartilhar` é `fg` (mesmo peso visual que `⋯`) quando não há link ativo, e vira `acc` sublinhado — literalmente o mesmo tratamento de um link — quando a nota já tem um link de compartilhamento ligado. Nunca só a cor: `acc` é próxima demais de `fg` neste sistema pra carregar um estado sozinha, e reaproveitar o estilo de link já existente é mais barato que inventar um novo sinal. O indicador de salvamento é sempre `meta`/`fg2`, nunca `acc` mesmo em erro (`sem conexão · não salvo` não é vermelho: o produto informa, não alarma).
