Um link só, que muda de modo — nunca dois links. A posição escolhida é indicada pela cor do próprio texto virando `acc` e pelo peso virando 700 — nunca só a cor, porque `acc` é próxima demais de `fg` neste sistema para se sustentar sozinha como sinal. Não adicione radio, checkbox ou ícone de seleção às três opções. A linha do link só aparece com `Só ver` ou `Pode editar`; ela é `meta` (recebe o mesmo tratamento tipográfico do metadado da lista) truncada com reticências, nunca quebrando linha. `Copiar` é um botão pequeno com a mesma regra do botão primário — borda de 1,5px em `acc`, texto `acc`, fundo da superfície ao redor (aqui `bg2`, porque está dentro do popover) — nunca um botão sozinho com fundo `acc`.

Este é um dos dois únicos lugares do produto com `shadow-1` e `radius-8` (o outro é o menu da nota e o toast). Sem fundo escurecido atrás — não é um modal.
